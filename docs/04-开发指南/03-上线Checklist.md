# 商业版上线 Checklist（v3.2）

> 面向生产交付。逐项核对，全部 ✅ 才允许发布。每项均对应已落地的实现或明确的人工运维动作。

## A. 初始化与账号

- [ ] `ENV=prod`，`JWT_SECRET` 为 ≥32 位随机串（启动会强校验，模板值直接失败）
- [ ] 已通过 `BOOTSTRAP_ADMIN_USERNAME/PASSWORD` 或 `python -m app.cli create-admin` 初始化管理员
- [ ] 初始口令符合强度策略（≥10 位、至少三类字符），且未使用任何示例/默认口令
- [ ] 初始化完成后已从部署环境移除 `BOOTSTRAP_ADMIN_PASSWORD`（或确认其仅在有管理员前生效）
- [ ] 已创建日常使用账号并按最小权限分配 admin / analyst / readonly
- [ ] 登录页无演示账号提示；前端构建产物中不含任何默认凭据

## B. 安全基线

- [ ] JWT 认证：登录/登出/过期处理；argon2 只存哈希
- [ ] 三档角色接口级生效（不只前端隐藏）；细粒度权限点守卫已启用
- [ ] 表级 ACL：SQLAgent 取数前校验；越权 403 + 审计；已按业务决定是否收紧为默认拒绝
- [ ] 登录防爆破：账号 + IP 双维度阈值已按业务调整，429 提示可验证
- [ ] 验证码一次性、TTL 生效；Redis 故障时内存降级可用
- [ ] 结果脱敏管道：手机号/身份证/邮箱
- [ ] Prompt 注入防护：输入结构化、工具白名单、事件白名单
- [ ] 审计日志追加写，应用层无 UPDATE/DELETE 接口；checksum 可校验
- [ ] 生产文档端点（`/docs`、`/redoc`、`/openapi.json`）已关闭
- [ ] HTTPS 全链路；CORS 仅白名单域名；WebSocket 首帧鉴权
- [ ] 数据源凭据不出现在非管理员响应中

## C. 稳定性与降级

- [ ] 调度租约/CAS/心跳自愈已接入监控，卡死任务可被回收
- [ ] `/readyz` 已接入编排/负载均衡；DB 不可用时返回 503
- [ ] MinIO 故障时本地盘降级可用（注意：不会自动回补，需人工归档）
- [ ] LLM 超时/限流时确定性兜底生效，报告不冒充实测数据
- [ ] SQL 只读 + `MAX_QUERY_ROWS` 大数据集保护
- [ ] Agent 成功率 / 耗时 / Token / 异常率告警
- [ ] 人工介入工作流：block/allow/rerun/abort 可用

## D. 数据与部署

- [ ] Alembic 迁移在发布流程自动执行且幂等
- [ ] 数据库 / MinIO / JWT / LLM 密钥均来自 Secret 管理，不进镜像、不进仓库
- [ ] 数据库与 MinIO 使用独立强口令（未沿用本地 `secret` / `minioadmin`）
- [ ] 生产 compose 使用 `compose.cloud.yml`，且 `.env` 已按 `.env.cloud.example` 填写
- [ ] MySQL 每日备份 + 恢复演练通过
- [ ] 前端静态产物构建通过，nginx SPA 回退 + `/api`、`/ws` 代理正确
- [ ] 日志结构化；`/healthz`、`/readyz` 探针已接入

## E. 测试与验收

- [ ] 后端 `pytest`、`ruff`、`mypy` 全绿
- [ ] 前端 `vitest`、`oxlint`、`tsc -b && vite build` 全绿
- [ ] 集成用例覆盖：DQ→FE 分支 / 复检升级 / 断点续跑 / 驳回重调度 / ACL 越权
- [ ] 用真实数据跑通一次端到端任务（含 DQ 阻断分支）
- [ ] 12-Agent E2E（`scripts/e2e_agents.py`）全绿或已记录环境差异
- [ ] 登录冒烟：正确口令成功、错误口令 401、连续失败 429、验证码一次性生效

## F. 非功能与运维

- [ ] 标准任务成本估算复核（Token 预算与实测偏差 <20%）
- [ ] 备份/恢复、告警接收人、值班流程就绪
- [ ] 已知限制（ACL 默认允许、知识库 LIKE 检索、MinIO 本地降级不回补）已与业务确认

## 发布顺序（建议）

```
A 初始化 → B 安全 → C 稳定性 → D 部署 → E 测试 → F 运维
任何一项未 ✅ 即视为未达到商业版上线标准。
```
