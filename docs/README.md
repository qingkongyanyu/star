## 阅读顺序建议

1. **产品/评审** → `项目架构书.md` → `功能与使用指南.md`
2. **开发负责人** → `01-项目结构/项目结构说明.md` → 后端/前端各目录文档
3. **后端工程师** → `02-后端/` 全部，重点 `06-Agent实现指南.md` 与 `07-配置与安全.md`
4. **前端工程师** → `03-前端/` 全部
5. **环境与上线** → `04-开发指南/`（尤其 `03-上线Checklist.md`）→ `云部署上手指南.md` → `05-DevOps/`
