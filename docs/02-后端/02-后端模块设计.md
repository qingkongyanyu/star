# 后端模块设计

> 分层架构：`api → services → repositories → infra`。本节给出每层职责、关键类、以及一个核心用例的调用链。

## 一、分层职责

| 层 | 目录 | 职责 | 禁止 |
| --- | --- | --- | --- |
| 路由层 | `app/api/v1/` | 参数校验、鉴权、序列化响应 | 业务逻辑、直接写库 |
| 服务层 | `app/services/` | 用例编排、领域逻辑、事务边界 | 直接接触三方客户端 |
| 数据访问层 | `app/repositories/` | 持久化（MySQL/MinIO/Redis） | 业务规则 |
| 基础设施层 | `app/infra/` | 封装三方客户端连接、会话管理 | 业务含义 |
| Agent 层 | `app/agents/` | 按 Agent 契约实现的 12 个 Agent（v3 新增洞察分析） | 越权访问其他 Agent 上下文 |
| 工具层 | `app/tools/` | Function Calling 工具实现与注册 | 直接 import api |

## 二、核心服务设计

### 1. `scheduler.py`（Planner 调度服务）

```python
class SchedulerService:
    def publish_task_pool(task_id, dag) -> None:
        """把 DAG 节点发布到任务池（TaskRepo），发 node.ready 事件。"""
    def arbitrate(node_id, candidates: list[AgentId]) -> AgentId:
        """认领仲裁：优先级 + 空闲度 + 历史成功率。"""
    def on_dq_blocked(blocked: DQBlockedEvent) -> NodeId:
        """dq.blocked 触发：新增 FE 节点、重接线下游依赖、发 node.ready。"""
    def on_review_rejected(rejected: ReviewRejectedEvent) -> None:
        """评审驳回：重调度对应节点迭代新版本。"""
    def on_timeout(node_id) -> None:
        """超时释放锁、回池、重试计数、升级人工。"""
    def human_override(node_id, action) -> None:
        """人工熔断：block/allow/rerun/abort，优先于自动决策。"""
```

**认领协议**（原子性靠 Redis Lua/SETNX + 状态 CAS）：

```
1. Agent 调 claim_task(capability)
2. Scheduler 从 READY 队列按能力取节点
3. SETNX task_lock:{node_id} → 成功则 UPDATE dag_node SET status=CLAIMED, claim_lock=token
4. 返回 node_id + token；失败返回空（回池）
```

```python
class MemoryService:
    def serve_search(query, scope, agent_id, top_k) -> list[MemoryHit]
```

## 三、Agent 主循环（`agents/base.py`）

```python
class AgentBase:
    CAPABILITY: str                     # 能力标签（认领用）

    async def run(self):
        while True:
            task = await self.claim()                       # 认领节点
            if not task: break
            ctx = await self.get_context(task.node_id)      # DAG 依赖 + 输入资产
            inputs = await self.pull_inputs(ctx)            # 从 ArtifactRepo 拉上游
            try:
                result = await self.execute(task, inputs)   # 子类实现：系统提示词 + 工具
                asset = await self.publish(task, result)    # 发布资产 + notify_bus
                await self.report_status("SUCCESS")
            except AgentError as e:
                if task.retry_count < 2:
                    await self.retry(task, e)
                else:
                    await self.report_status("FAILED"); await self.release(task)
```

记忆时机：执行前 `recall_memory(query)`；复盘时 `submit_experience_summary`。

## 四、核心用例调用链：DQ 阻断 → 特征工程

```
SQLAgent.execute
  └ tools.execute_read_only(sql)            → infra/db（SELECT）
  └ tools.publish_artifact(dataset)         → artifact_service.publish → artifact_repo
  └ notify_bus(artifact.published)          → bus/producer → Kafka
DataQualityAgent.execute
  └ tools.run_quality_checks(dataset)       → 质检规则（services/quality.py）
  └ tools.notify_blocked(...)               → bus 发 dq.blocked
bus/consumer
  └ scheduler.on_dq_blocked(event)          → dag_service.reroute + 发 node.ready
FeatureEngineer.execute
  └ tools.clean_dataset(dataset)            → services/feature_pipeline.py
  └ publish_artifact(feature_set)           → 触发 DataQuality 复检
DataQualityAgent.recheck
  └ recheck_dataset(feature_set)            → 通过→dq.passed；失败→retry≤2→升级人工
```
