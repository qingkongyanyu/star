## 二、初始管理员（无默认账号）

平台启动时执行 `ensure_bootstrap_admin()`：

1. 库中已有启用管理员 → 不做任何修改（不会重置线上口令）；
2. 无管理员且配置了 `BOOTSTRAP_ADMIN_USERNAME/PASSWORD` → 校验口令强度后创建；
3. 无管理员且未配置 → 开发环境 warning，**生产环境启动失败**并给出修复指引；
4. 配置的用户名已存在但不是管理员 → 不自动提权（避免越权），提示改用 CLI。

运维 CLI（在 `backend/` 下执行，读取 `backend/.env`）：

```bash
python -m app.cli create-admin --username admin
python -m app.cli reset-password --username admin
python -m app.cli list-admins
```

口令来源优先级：`--password` → `BOOTSTRAP_ADMIN_PASSWORD` 环境变量 → 交互输入两次。
所有操作写审计日志（`user.created` / `user.password_reset`，`actor=cli`）。

### 口令强度策略（`core/security.py`）
- 长度 ≥ `PASSWORD_MIN_LENGTH`（默认 10）；
- 非常见弱口令（内置黑名单）；
- 至少包含大写、小写、数字、符号中的三类；
- 只存 argon2 哈希。

策略同时作用于：初始管理员、CLI 重置、管理员新增用户（`POST /admin/users`）。

## 三、认证与角色（`core/security.py`）

### 密码与令牌
- 密码：`argon2`，只存哈希；校验在线程池执行，不阻塞事件循环。
- 令牌：JWT（HS256），载荷 `{ sub, role, exp }`；`/auth/login` 校验通过签发。

### 登录链路（v3.2）
1. `GET /auth/captcha`：生成一次性验证码（异步 Redis；不可用降级内存，TTL 300s）；
2. `POST /auth/login`：
   - 先查账号/IP 失败计数，超限直接 429 `E_RATELIMIT`（带剩余秒数）；
   - 校验验证码（一次性、大小写不敏感）；
   - 校验口令；任何失败都会累计失败计数（统一提示「账号或密码错误」，不泄露账号是否存在）；
   - 成功清零计数并签发 JWT。
3. 登录失败限流实现：`infra/login_throttle.py`，Redis 计数多实例共享，Redis 故障进入 30s 冷却并降级进程内存。

## 四、表级 ACL（`repositories/acl_repo.py` + SQLAgent）

- ACL 存储：`admin_acl` 表 `{ role_or_user, table, action, allow }`。
- SQLAgent 执行前必经 ACL 校验；拒绝优先于允许；无规则默认允许（只读连接），生产可收紧为默认拒绝。
- 执行上下文取**真实用户角色**（`base.py` 按 `task.requester` 查 user 表）。
- 规则管理：POST/PUT/DELETE `/admin/acl`，前端 ACL Tab 按规则增删改。

```python
}

def mask_dataset(data): ...
```

- SQLAgent 取数后必过 `mask_dataset` 自动脱敏；未声明敏感字段但命中规则 → 审计告警。
- 数据源凭据脱敏：分析师等非管理员用 `/data-sources/options`（不含 config/密码）选择数据源。

## 六、Prompt 注入防护

1. **输入隔离**：用户需求作为业务参数结构化传入，不进系统提示词。
2. **输出护栏**：工具返回的 `content` 视为不可信数据，展示端转义；不允许 LLM 拼接系统指令。
3. **白名单工具**：每个 Agent 只能调用其契约允许的工具集（`registry` 按 CAPABILITY 过滤）。
4. **事件白名单**：`notify_bus` 仅允许本 Agent 契约事件类型。

## 七、审计（`repositories/audit_repo.py`）

- 追加写：表结构见 `03-数据模型与迁移.md`；应用层**不提供 UPDATE/DELETE 接口**。
- 摘要校验：`checksum = SHA-256(detail)`；巡检任务定期校验链完整性。
- 审计查询支持 actor / action / asset_id / 时间范围筛选。

## 八、生产安全基线（`ENV=prod`）

| 项 | 行为 |
| --- | --- |
| JWT 密钥 | 默认值或长度 <32 位 → 启动失败 |
| 初始管理员 | 无管理员且未配置 `BOOTSTRAP_ADMIN_*` → 启动失败 |
| API 文档 | `/docs`、`/redoc`、`/openapi.json` 关闭（返回 404） |
| 响应头 | `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`；生产追加 HSTS 与严格 CSP |
| CORS | 仅允许 `CORS_ORIGINS` 白名单 |
| 探针 | `/healthz` 存活；`/readyz` 并发探测 DB/Redis/MinIO（DB 不可用返回 503） |
| WebSocket | 首帧鉴权，token 不进 URL |

## 九、降级策略

| 依赖 | 故障 | 降级动作 |
| --- | --- | --- |
| MinIO | 不可用 | 资产写本地盘（`backend/data/artifacts/`），不自动回补 |
| MySQL | 不可用 | 不静默降级：`/readyz` 返回 503，调度租约无法推进 |
| LLM | 超时/限流 | 重试退避 → 失败回退确定性逻辑（诚实降级，绝不编造数据） |
| Redis | 不可用 | 验证码/登录限流回落进程内存；事件总线回落进程内广播 |

## 十、通用限流工具

`infra/redis.py` 提供 Redis 令牌桶（`token_bucket_allow`）与锁（`acquire_lock/release_lock`）作为通用能力；
当前**已启用**的限流是登录防爆破；任务下发/大屏接口的令牌桶尚未接线，如需启用应在对应服务入口显式调用。
