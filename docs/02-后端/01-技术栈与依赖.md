## 三、Python 3.13 兼容注意

1. **不再依赖旧版 typing 扩展**：`typing.Self`、`type[X]`、`|` 联合类型均已内置，无需 `from __future__ import annotations`（除非兼容 3.12）。
2. **密码哈希**：使用 `argon2-cffi`（PyPI 有 3.13 wheel），`PASSWORD_HASHER=argon2`。
3. **pydantic-core / sqlalchemy**：均为 Rust/C 扩展，需 `pip` 源支持 cp313 wheel；默认 PyPI 即可。
4. **asyncio**：Python 3.13 已默认 `uvloop` 不适用 Windows，本地开发用 `uvicorn` 自带 event loop；生产 Linux 可 `pip install uvicorn[standard]` 获得 uvloop。

## 四、环境隔离

```bash
# 推荐 uv（也可用 venv + pip）
uv venv .venv --python 3.13.2
uv pip install -e ".[dev]"
```

**禁止**：直接 `pip install` 到全局环境；生产镜像固定 lock 文件（`uv.lock` 或 `requirements.lock`）。

## 五、目录级依赖对齐

| 模块 | import 范围 |
| --- | --- |
| `app/infra/*` | 唯一允许 import 三方客户端的地方 |
| `app/repositories/*` | 仅 infra + core（不 import services/api/agents） |
| `app/services/*` | repositories + infra + core + schemas |
| `app/agents/*` | services + tools + bus + infra/llm |
| `app/api/v1/*` | services + schemas + core（不 import agents 直接执行） |
