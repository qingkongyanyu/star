# 前端技术栈与工程化

> 前端与后端物理分离，仅通过 REST + WebSocket 通信。主平台为**秋季浅色暖色调**，登录页独立主题（山湖实景 + 枫叶动效）。

## 一、技术栈（以 `frontend/package.json` 为准）

| 领域 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | React 19 + TypeScript 6 | 严格模式，全量 TS |
| 构建 | Vite 8 | dev 代理 `/api`、`/ws` 到后端 |
| UI 组件库 | Ant Design 6 | 中台表单/表格/布局 |
| 图表 | ECharts 6 | 大屏、任务工作台、资产预览 |
| DAG / 血缘 | 自研 SVG 组件 `DagGraph` | 无 G6 依赖，按拓扑深度列布局 |
| 状态 | Zustand 5 | 轻量、无样板代码 |
| 请求 | axios + 原生 WebSocket | `api/` 层统一封装 |
| 路由 | React Router 7 | 登录 + 主布局，懒加载 |
| 样式 | CSS + CSS 变量 | 主题令牌 `config/theme.ts` |
| 包管理 | npm | 提交 `package-lock.json` |

## 二、工程约定

### TypeScript 严格度
```json
// tsconfig.app.json 关键项
{ "strict": true, "noUncheckedIndexedAccess": true,
  "noUnusedLocals": true, "noUnusedParameters": true,
  "noFallthroughCasesInSwitch": true }
```

### 命名规范
| 类型 | 命名 |
| --- | --- |
| 组件文件 | `PascalCase.tsx`（`DagGraph.tsx`） |
| Hook | `useXxx.ts`（`useECharts.ts`） |
| store | `xxxStore.ts`（`authStore.ts`） |
| 类型/接口 | `PascalCase`，放 `types/` |
| 常量/枚举 | `SCREAMING_CASE` 或 `PascalCase` enum |

### 代码检查
- `oxlint` 负责 lint；`npm run lint`。
- 提交前 `npm test && npm run lint && npm run build`（CI 强制执行）。

### 主题单一来源
- 主平台色板：`src/config/theme.ts` 的 `T`；antd 令牌由 `src/config/antdTheme.ts` 派生。
- 登录页使用独立的暖色 `ConfigProvider`，不影响主平台。
- 禁止在页面里散落硬编码色值。

## 三、Dev 代理（`vite.config.ts`）

```ts
server: {
  proxy: {
    '/api': { target: 'http://localhost:8070', changeOrigin: true },
    '/ws':  { target: 'http://localhost:8070', changeOrigin: true, ws: true },
  },
}
```

## 四、质量门槛

- 页面必须 `npm run build` 通过（`tsc -b` + Vite 产物）。
- 新增依赖走评审；图表统一使用 ECharts，不再引入第二套图表库。
- 所有对外文案中文；避免 `console.log` 残留。
- 登录页与安全相关改动必须遵守 `docs/03-前端/05-权限与安全.md`（无演示账号、不存口令、429 提示）。
