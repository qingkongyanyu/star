# 前端目录结构与组件

> 完整目录树见 `docs/01-项目结构/项目结构说明.md`。本节说明 `src/` 各目录职责与当前实际组件。

## 一、src 目录职责

```
src/
├── main.tsx          # 挂载路由 + antd 主题 + 全局样式
├── index.css         # 全局样式
├── api/              # 唯一 import axios/WebSocket 的层
│   ├── http.ts       #   axios 实例：JWT 注入、401 → 跳登录、错误统一处理
│   ├── ws.ts         #   WebSocket：连接/重连、首帧鉴权、事件分发
│   └── *.ts          #   auth/task/asset/agents/memory/dashboard/dataSource/admin
├── stores/           # Zustand：authStore / chatStore / wsEvents
├── layouts/          # MainLayout：侧边栏 + 顶栏 + 内容区
├── pages/            # 页面（见下表）
├── components/       # 跨页面复用组件
├── config/           # 主题/Agent/静态资源/文案常量
├── router/           # 路由表 + 登录/角色守卫
├── types/api.ts      # 后端 schema 对齐的 TS 类型
└── test/setup.ts     # vitest + Testing Library 基建
```

## 二、布局

| 组件 | 职责 |
| --- | --- |
| `MainLayout.tsx` | 侧边栏导航 + 顶栏（用户/退出）+ `<Outlet/>`；按角色裁剪管理入口 |

| 组件 | 说明 | 使用页面 |
| --- | --- | --- |
| `DagGraph.tsx` | 自研 SVG DAG：拓扑深度列布局、节点状态色、边类型、点选回调 | 任务看板/工作台 |
| `ChartRenderer.tsx` | ECharts 图表渲染（按后端 chart spec 渲染） | 工作台大屏/资产预览 |
| `useECharts.ts` | ECharts init/resize/dispose 生命周期 Hook | 配合 ChartRenderer |
| `MarkdownView.tsx` | 报告 Markdown 渲染（GFM） | 报告预览/资产预览 |
| `AssetPreviewModal.tsx` | 资产内容预览弹窗（报告/JSON/SQL） | 资产仓库/工作台 |
| `ErrorBoundary.tsx` | 页面级错误兜底 | 路由层 |
| `MapleLeaves.tsx` | 登录页枫叶动效（尊重 reduced-motion） | 登录页 |

## 五、组件复用规则

1. 一个组件出现在 ≥2 个页面 → 上提 `components/`；仅单页使用 → 留在页面目录内。
2. 组件不直接创建 axios 实例；统一经 `api/` 层与 store/props。
3. 主题色只从 `config/theme.ts` / `config/antdTheme.ts` 取，禁止页面内散落色值。

## 六、登录页与安全

- 登录页独立暖色主题（山湖实景 + 枫叶动效），不污染主平台秋季主题。
- 账号/口令/图形验证码三项必填；验证码一次性、可刷新；Caps Lock 提示。
- 页面不展示任何演示账号；429 时展示后端返回的剩余锁定秒数。
