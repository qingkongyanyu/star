## 二、权限守卫

```tsx
// 未登录 → /login
function RequireAuth({ children }) {
  const { user, token } = useAuthStore();
  return token ? children : <Navigate to="/login" replace />;
}
// 角色门槛（一期：admin 专属模块）
function RequireRole({ role, children }) {
  const { user } = useAuthStore();
  return user.role === role ? children : <Navigate to="/task-board" replace />;
}
```

| 模块 | 登录即可 | 需 admin |
| --- | --- | --- |
| 群聊 / 任务看板 / 资产仓库 / 大屏 | ✅ | — |
| 系统管理 / 记忆检索中心 | — | ✅ |

（`readonly` 角色进入后可看只读模块，操作按钮由 `useAuth()` 按角色禁用。）

## 四、关键交互（对应用户评审点）

1. **群聊 → 工作台**：任务完成消息提供「查看任务工作台 →」，路由到 `/task/:taskId`。
2. **DAG 点选**：`DagGraph` 支持节点点选；节点详情由任务工作台/看板按 `node_id` 展示。
3. **DQ→FE 分支可视化**：`/tasks/{id}/dag` 返回的 edge 含 `quality_block` 类型，自研 SVG `DagGraph` 用橙色虚线 + 标签渲染；FE 节点高亮。
4. **实时刷新**：`api/ws.ts` 收到事件后写入 `chatStore`（群聊发言）与 `wsEvents`（事件信号）；任务看板/工作台订阅 `wsEvents.lastEvent` 后重新拉取 DAG/资产。
5. **大屏轮询**：`/dashboard/*` 每 60s 轮询；WebSocket 事件触发即时刷新。

## 五、登录态与 401

- `api/http.ts` 请求拦截器注入 `Authorization: Bearer <token>`。
- 响应 401 → 清空 `authStore` → 跳 `/login`（保留来源路由，登录后回跳）。
- token / 用户信息存 localStorage（`auth-token` / `auth-user`）；「记住账号」只额外保存用户名，**不保存口令**。
