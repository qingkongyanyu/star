## v3.2 · 商业版交付（2026-10-19）

从「可演示」升级为「可交付商业版」：移除全部演示账号痕迹，补齐生产安全基线，增强异步链路，清理项目与文档。

- **无默认账号**：删除启动时自动创建 `admin/admin123` 的行为与登录页演示提示；初始管理员改为
  `BOOTSTRAP_ADMIN_*` 或 `python -m app.cli create-admin` 显式创建；生产环境缺失初始化配置直接启动失败。
- **账号运维 CLI**：`backend/app/cli.py` 提供 `create-admin` / `reset-password` / `list-admins`，所有操作写审计。
- **口令强度策略**：≥10 位、非常见弱口令、至少三类字符；作用于初始管理员、CLI 重置、管理员新增用户。
- **登录防爆破**：账号 + 来源 IP 双维度失败计数（默认 5 次 / 30 次，锁定 900s），Redis 多实例共享、故障内存兜底，超限 429。
- **验证码异步化**：`infra/captcha.py` 改用 `redis.asyncio`，消除登录链路同步 Redis 阻塞；Redis 故障自动降级内存。
- **生产安全基线**：强 JWT 校验（≥32 位）、生产关闭 `/docs` 等文档端点、安全响应头（HSTS/CSP/X-Frame-Options 等）、CORS 白名单。
- **就绪探针**：新增 `/readyz`，并发探测 DB / Redis / MinIO；DB 不可用返回 503，其余降级返回 `degraded`。
- **异步增强**：Agent 上游资产并发拉取（独立会话 + 可配置并发上限）；Redis 客户端增加连接/读写超时。
- **工程清理**：删除缓存/日志/PID/构建产物/IDE 配置/历史备份/本地降级资产，以及被 docs 取代的根目录历史规格书、原型 HTML、重复使用手册。
- **文档同步**：README、文档地图、环境搭建、配置与安全、API 契约、上线 Checklist、云部署指南统一为商业版口径；11-Agent 残留表述统一改为 12-Agent。

## v3.0 · 商业级重构（2026-10）
demo → 商业项目的完整重构：前后端全面梳理、功能全部落地、文档与代码对齐。

- **架构收敛**：移除未用的 PostgreSQL（LangGraph 检查点）、Qdrant（向量记忆）、LangChain/LangGraph 依赖；收敛为精简单库（MySQL 双库 + Redis + MinIO + Kafka）。
- **数据脱敏落地**：手机号/身份证/邮箱字段自动脱敏（`infra/datasource.py` mask_dataset），SQL 取数后应用。
- **细粒度 RBAC 落地**：`require_permission(permission)` 依赖，权限点真正生效（资产下载等）。
- **WebSocket 首帧鉴权**：token 从 URL query 改为首帧 `{type:"auth", token}`，避免泄露到访问日志。
- **前端工程化**：开启 strict + noUncheckedIndexedAccess、路由懒加载 + ErrorBoundary、主题令牌单一来源、公共常量/组件抽取、vitest + Testing Library 测试基建。
- **Bug 修复**：retry_count 递增、parquet 扩展名错位、约束名漂移、同步 commit 阻塞事件循环、后端容器崩溃循环、真实密钥泄露等。
