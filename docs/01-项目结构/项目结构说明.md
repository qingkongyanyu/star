# 项目结构说明

> 本文件定义中台仓库的**唯一目录规范**。所有代码必须落入对应目录，新目录需在本文件登记。

## 一、顶层总览

```
data-mid-platform/                      # 仓库根（即当前项目目录）
├── README.md                           # 仓库首页：简介 + 文档索引 + 启动最快路径
├── docker-compose.yml                  # 本地开发基础设施（MySQL/Redis/Kafka/MinIO）
├── compose.cloud.yml                   # 商业版全链路编排（中间件 + 后端 + 前端）
├── backend/.env.example                # 后端环境变量模板（禁止提交真实密钥）
├── .env.cloud.example                  # 生产 compose 环境变量模板
├── .gitignore
├── docs/                               # ← 本文档集（与源码同步的事实来源）
├── backend/                            # 后端（Python 3.13.x / FastAPI）
├── frontend/                           # 前端（React + Vite + TS）
├── scripts/                            # 启动/健康检查/E2E/初始化脚本（非应用代码）
└── Data/                               # 演示 CSV（E2E 与手工演示）
```

**核心约束**：
- 后端与前端**物理隔离**，各自独立依赖、独立构建、独立部署，仅通过 REST + WebSocket 通信。
- 代码只落在 `backend/`、`frontend/`、`scripts/`；文档在 `docs/`；演示数据在 `Data/`。
- `docker-compose.yml` 只起**中间件**；应用容器化走 `compose.cloud.yml` 与各自 Dockerfile。

**后端分层依赖规则（强约束）**：
```
api → services → repositories → infra / 三方客户端
api → schemas（DTO 双向）
agents → tools / services / repositories（经 bus 交互，不直接调 api）
repositories 不得 import api / services / agents
```
违反该依赖方向视为架构违规，评审拦截。

**执行引擎当前状态（v2.x）**：`app/agents/` 已实现 10 个执行 Agent + Planner；由
`services/scheduler_worker.py` 常驻 Worker 凭 **DB 租约/CAS** 多 worker 安全推进 DAG
（崩溃自愈、心跳续租），`scheduler.py` 负责单节点执行与分支仲裁（DQ→FE 前置清洗、终审修订轮、
失败整链重跑）。数据源：mysql/postgres/olap 走真实 SQL；file/api/stream（记录型）走真实拉取→
`sql_agent._aggregate_records` 聚合。溯源节点（TraceNavigator）输出确定性血缘/责任（trace_service
grounded），绝不编造表/人。事件默认进程内广播，多副本开 Redis Pub/Sub。`app/tools/` 提供
registry + task/artifact/memory 共享工具；指标/记忆/ACL/审计贯穿全程。

## 五、命名与放置规则（速查）

| 场景 | 放置位置 | 反例 |
| --- | --- | --- |
| 一个新 REST 端点 | `app/api/v1/<模块>.py` + `schemas/` | 塞进 services 直接返回 |
| 一个新 Agent | `app/agents/<name>.py` + `tools/` 里注册工具 | 在 api 层写 Agent |
| 一个新数据库表 | `alembic/versions/` 迁移 + `repositories/task_repo.py` | 手写 SQL 建表 |
| 一个新前端页面 | `pages/<Name>/index.tsx` + 路由表登记 | 塞进 App.tsx |
| 一个新共用组件 | `components/<Name>.tsx` | 页面内复制粘贴 |
| 环境相关差异 | `.env` + `core/config.py` | 代码里写死 IP/密钥 |
