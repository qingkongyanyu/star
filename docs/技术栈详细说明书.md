> 版本：v3.2 商业版（2026-10-19）｜ 前后端分离 ｜ 工程化工具：uv / npm / Alembic / Docker Compose

## 六、配置体系（backend/.env）

详见 `docs/02-后端/07-配置与安全.md`。关键配置：
- 双库 URL（`DATABASE_URL` → task_repo / `ARTIFACT_DATABASE_URL` → artifact_repo）
- 中间件地址（Redis/Kafka/MinIO 默认 `127.0.0.1`）
- LLM（`LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`，OpenAI 兼容；`LLM_TIMEOUT_SECONDS` / `LLM_MAX_RETRIES` 韧性）
- 认证（`JWT_SECRET` / `PASSWORD_HASHER=argon2` / `BOOTSTRAP_ADMIN_*` / `PASSWORD_MIN_LENGTH` / `LOGIN_*`）
- 事件总线（`EVENT_BUS_REDIS` 多副本开关）
- 取数上限（`MAX_QUERY_ROWS`，默认 5000）
- 调度租约（`SCHEDULER_LEASE_TTL` / `SCHEDULER_MAX_CONCURRENT` 等）

## 八、已知技术要点

- **Kafka 镜像**：`apache/kafka:3.7` 在 Docker Hub 不存在，必须用 `3.7.1` 等补丁版本
- **后端热重载**：本机 uvicorn `--reload` 不可靠（残留旧进程占端口），改代码后手动重启
- **前端主题**：主平台浅色秋季主题（`config/theme.ts` 单一色板），登录页使用独立的暖色山湖主题
- **Agent 命名**：拟人化「名称_职称」（天枢_调度…洛璃_终审），定义在 `constants.py` / `config/agents.ts`
- **诚实降级**：LLM 不可用时回退确定性逻辑，绝不编造数据；取数超过 `MAX_QUERY_ROWS` 截断并标注 truncated
