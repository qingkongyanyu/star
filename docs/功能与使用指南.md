> 版本：v3.2 商业版（2026-10-19）｜ 面向最终用户｜ 登录：使用管理员为你分配的账号（平台无内置账号）

## 二、三种下发任务方式

### 方式一：协同群聊（最直观）
1. 「协同群聊」→ 确认输入框左边已选数据源（自动选第一个已连接）
2. 输入需求（如"分析订单表 orders 各区域销售额"）→ 发送
3. 看到 **天枢_调度 → 素问_指标定义 → 观澜_数据探查 → 灵枢_SQL抽取 → 明鉴_数据质检 → 丹青_可视化 → 天机_洞察分析 → 文澜_报告编撰 → 洛璃_终审** 依次以自己身份发言（脏数据时炼金_特征工程、溯源需求时闻道_溯源也会加入）
4. 跑完点「查看任务工作台 →」

### 方式二：任务看板（能选数据源 + 看 DAG）
1. 「任务看板」→ 左边选数据源 → 输入需求 → 下发
2. 上方进度流程图实时动，跑完点「工作台」

### 方式三：任务工作台（看历史）
- 「任务工作台」→ 列出所有任务 → 点任意一个 → 看它自己的大屏/资产/记忆

## 三、核心功能详解

### 协同群聊（Agent 发言流）
- 消息按 Agent 头像 + 名字显示（如"洛璃_终审 · 14:30"）
- 任务完成消息带「查看任务工作台 →」按钮
- 无可用数据源时红字提示并阻止发送

### 任务工作台 · 数据可视化大屏
- 渲染该任务**最终分析结果**：多数据集 KPI + 折线/柱状/条形/环形/树图/散点/瀑布等多类型图表 + 关键洞察 + 数据明细表格 + 完整报告
- 图表由服务端根据「意图 + 数据结构 + 特征工程建议 + 用户点名图型」选择，并给出选择理由
- 每个任务独立加载，切任务即刷新，不复用上一个任务数据

### 分析报告
- **动态结构**（随意图变化）：关键结论 → 各分析主题（图 + 表 + 解读）→ 数据质量与口径 → 风险与建议 → 附录
- 每张图有图号图题、每张表有表号，正文引用图号；无数据时明确写「无数据，不出图」
- **数字 100% 来自真实数据**（确定性生成，不编造）
- 预览：Markdown + 内嵌交互图表；下载：`.md` 文件（图表自动转成内嵌 PNG，离线也能看图）

### 意图驱动的差异化分析（v3）
- 天枢先把需求拆成结构化计划：分析类型 × 指标 × 维度 × 时间粒度 × 过滤 × TopN × 图表偏好
- 同一份数据的不同问法会得到不同指标、不同维度、不同图型和不同报告章节，例如：
  - 「2025 年各月销售额走势」→ 月粒度折线 + 分时段柱状对比
  - 「各商品类目销售额占比」→ 环形图 + 排序柱状图
  - 「销售额和订单量有什么关系」→ 散点 + 回归线 + 相关系数
  - 「对比各区域销售额并溯源根因」→ 对比柱 + 瀑布贡献拆解 + 溯源
- 指标来自真实字段；算不出的指标（如缺成本列时的毛利率）会明确标注不可行，不硬套模板

### 数据源接入
| 类型 | 说明 |
|---|---|
| MySQL / PostgreSQL | 填 host/port/库/账号/密码，测试连接 → 列表 → 结构预览；真实 SELECT 取数 |
| OLAP | 填 SQLAlchemy 连接串（MySQL/Postgres 类可直连）；真实取数 |
| CSV 文件 | 拖拽上传，自动解析列类型并注册；真实读取聚合 |
| Kafka 流 | bootstrap + topic，读取 topic 内保留的 JSON 消息（只读不推进位点）；真实取数 |
| 外部 API | URL + 鉴权，测试并推断 JSON 字段；请求返回 JSON 记录真实取数 |

> ✅ v2.2：6 类数据源**全部支持真实取数并产出报告**（SQL 直连 / CSV / API / Kafka 统一聚合链路）。

**演示数据源**：本地可用 docker MySQL 的 `sales_demo.orders`，或上传仓库 `Data/` 下的 CSV（电商数据 / 电商多维演示）；Postgres/OLAP/Kafka/API 按需接入外部实例。`scripts/e2e_agents.py` 会自动拉起临时 API 与 Kafka 场景，仅用于验收。

## 五、知识库（指标口径）

- 位置：系统管理 → 知识库
- 预置 7 条口径（销售额/GMV/订单量/客单价/退款率/转化率/分城市销售额）
- 管理员维护口径 → **Agent 定义指标时优先采用**（报告指标口径章节跟着变）
- 支持新增/编辑/删除（公式、描述、标签）

## 六、表级 ACL

- 位置：系统管理 → ACL
- 规则：`角色或用户 × 表(支持 *) × 操作 × 允许/拒绝`
- 例：新增 `analyst + orders + select + 拒绝` → 分析师取 orders 表被拦（取数不执行、无数据）
- 策略：拒绝优先于允许；无规则默认允许（只读连接）

## 七、常见问题

| 问题 | 解答 |
|---|---|
| 首次登录不知道账号 | 平台无内置账号；由管理员通过 `BOOTSTRAP_ADMIN_*` 或 `python -m app.cli create-admin` 初始化 |
| 群聊说"没有数据" | 先到「数据源接入」连接一个数据源，或在群聊/任务看板选上 |
| 登录提示 429 | 账号或来源 IP 连续失败触发了防爆破锁定，等待锁定时间后重试或联系管理员 |
| 切账号任务不见了 | 不会，任务全局共享，只是管理菜单按角色隐藏 |
| 报告下载是乱码 | 下载为 .md/.sql/.json；如遇历史文件编码问题请重新生成 |
| DAG 流程图卡住 | 右上角 ✕ 可关闭，或切到任务工作台 |
| 忘记口令 | 联系管理员用 `python -m app.cli reset-password --username <账号>` 重置 |
